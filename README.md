# GameStore MVC

GameStore MVC is an academic web development project created as part of the **Tecnologies de Desenvolupament per a Internet i Web (TDIW)** course at the **Universitat Autònoma de Barcelona (UAB)**, within the Computer Engineering degree.

The project consists of an online store focused on video games and other entertainment products, developed to apply web development concepts and the **Model-View-Controller (MVC)** architectural pattern.

## Technologies

- **PHP** – Server-side development
- **HTML & CSS** – Web structure and styling
- **JavaScript** – Client-side functionality
- **MVC Architecture** – Separation of application logic, data management and presentation

## Project Structure

The application is organized into the following directories:

```text
GameStore-MVC/
├── controller/    # Application controllers
├── model/         # Data access and business logic
├── view/          # User interface
├── css/           # Stylesheets
├── js/            # JavaScript files
├── img/           # Images
└── recursos/      # Additional resources
```

## Academic Context

This project was developed for the TDIW course at UAB as a practical exercise in web application development.

Its main purpose was to gain hands-on experience with server-side and client-side technologies, application architecture, and the development of dynamic web applications.

## Project Status

This repository contains the source code of the original university project. The application is not currently deployed, and its execution may require additional server and database configuration.
